# EWB JavaScript Internship — Assignments and Capstone

This repository contains six JavaScript practice assignments and the capstone mini project based on the assignment document shared by EWB.

## Files
1. `Assignment_1_Variables.js` — variables, data types, and console output.
2. `Assignment_2_Operators.js` and `Assignment_2_Operators.html` — prompts, type conversion, operators, and bill/tip calculation.
3. `Assignment_3_Conditions.js` — if/else, switch, and ternary operator.
4. `Assignment_4_Loops.js` — for, while, break, do...while, and continue.
5. `Assignment_5_Functions.js` — standard/arrow functions, defaults, and block scope.
6. `Assignment_6_Arrays.js` — product objects, forEach, filter, and map.
7. `Capstone_Product_Inventory.html` — interactive product inventory and analytics dashboard.

## How to run
- For `.js` files 1, 3, 4, 5, and 6: run with Node.js (`node filename.js`) or paste into a browser developer console.
- Assignment 2 uses `prompt()`. Open `Assignment_2_Operators.html` in a browser and check the developer console.
- For the capstone, open `Capstone_Product_Inventory.html` in a browser. Add products and change the tax rate to test it.
